# AP Poll Sucks — CFB

College football rankings website for **appollsucks.com/cfb**.

## Current prototype

This first version contains a responsive rankings homepage, ranking movement, weekly games, and methodology section.

**Important:** the ranking numbers currently in `app.js` are prototype/demo data. The next build will replace them with live college-football data and the actual AP Poll Sucks ranking formula.

## Planned stack

- GitHub
- GitHub Pages or Cloudflare Pages
- HTML/CSS/JavaScript for the initial frontend
- Free college-football data source for the data layer
- Automated weekly ranking calculation
